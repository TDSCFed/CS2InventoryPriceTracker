# CS2InventoryPriceTracker

Android app (.NET MAUI) to see a Counter-Strike 2 Steam inventory and the current price of each item, in euros.

## Features

- Loads the CS2 inventory of a public Steam profile (SteamID64, profile link or custom URL name)
- Current price of every marketable item on the Steam Community Market, Skinport and Market.CSGO, plus quantity and
  total value (choose which market the totals use, or the cheapest one)
- Search, sort (value, unit price, name, quantity) and hide unmarketable items
- Optional Steam login to see what is inside storage units, with the value of each storage unit
- History tab: value of the whole account or of one storage unit over time (7/30/90 days or all), on any market
- Inventory and prices are kept on the phone, so the app opens instantly and works offline

## Download

Every build of `main` is published as the **latest** release:
https://github.com/TDSCFed/CS2InventoryPriceTracker/releases/latest/download/CS2InventoryPriceTracker.apk

Every pull request gets its own pre-release, and the download link is posted as a comment on the PR.

CI signs every APK with the same key, so new builds install over the old one and keep the app data. The key comes from
two repository secrets: `ANDROID_KEYSTORE_BASE64` (the PKCS12 keystore, base64) and `ANDROID_KEYSTORE_PASSWORD`
(alias `cs2inventory`). Without them the APK is signed with a temporary debug key. Builds from Rider use your local
debug key, so switching between a Rider build and a CI APK needs an uninstall.

## Setup

1. In Steam, make your profile and inventory public (Edit Profile > Privacy Settings).
2. Open `CS2InventoryPriceTracker.slnx` in Rider, select your phone (USB debugging on) or an emulator, and run.
3. In the app, open the **Account** tab and paste your Steam profile link.

Command line alternative:

```
dotnet build CS2InventoryPriceTracker/CS2InventoryPriceTracker.csproj -t:Run -f net10.0-android
```

No API keys are needed: the app uses Steam's public inventory and market price endpoints, and the public price lists
of Skinport and Market.CSGO.

## Storage units

The public Steam inventory only shows the storage units themselves, not their contents. To read them, log in to Steam
in the **Account** tab (Steam Guard is supported: approve in the Steam app or type a code). The app then briefly starts
CS2 on the account through the CS2 Game Coordinator ([SteamKit2](https://github.com/SteamRE/SteamKit)), reads every
storage unit and leaves the game again. Close CS2 on your PC before loading storage units.

The password is only sent to Steam. The app keeps the Steam refresh token in the phone's secure storage; **Log out**
removes it.

The Game Coordinator only returns item ids, so names come from `Resources/Raw/items.json`, generated by
`tools/generate_item_data.py` from [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API). CI regenerates it on every
build; run `python tools/generate_item_data.py` to update the committed copy.

## Prices

Every market is a `IPriceProvider`; they all refresh at the same time and each card lists the price on every market.
The **Account** tab chooses which market values and totals use (Steam Market by default, or the cheapest market).

| Market | How | Refreshed |
| --- | --- | --- |
| Steam Market | one request per item, about 20 per minute | every 12 hours |
| Skinport | `api.skinport.com/v1/items`, every item at once (Brotli required) | every 30 minutes |
| Market.CSGO | `market.csgo.com/api/v2/prices/EUR.json`, every item at once | every 30 minutes |

Prices are cached in SQLite (or refreshed on demand with **Update prices** in the menu). The price shown is the cheapest
current listing, or the median sale price when nothing is listed. Bulk markets are subclasses of `BulkPriceProvider`,
so adding another one only needs its download and parsing.

## Structure

- `Models/` - SQLite entities (inventory lines, cached prices, daily value snapshots and price history)
- `Services/` - `SteamInventoryService` (profiles and inventory), `IPriceProvider` with `SteamMarketPriceProvider`,
  `SkinportPriceProvider` and `CsgoMarketPriceProvider`, `PriceUpdater` (background price refresh), `SteamSessionService` (Steam login and CS2 Game Coordinator),
  `StorageUnitService` + `ItemCatalog` (storage unit contents), `LocalStore` (SQLite) and `SettingsService`
- `tools/` - `generate_item_data.py` (item names for storage unit contents)
- `Controls/` - `LineChartDrawable` (charts drawn with MAUI graphics, no chart library)
- `ViewModels/` - MVVM view models (CommunityToolkit.Mvvm)
- `Views/` - pages (XAML)
